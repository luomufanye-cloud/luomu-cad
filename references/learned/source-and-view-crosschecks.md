# 资料来源与视图互证工作流

日期：2026-11-03T23:43:43+08:00

摘要：经审阅的绘图工作方法，附来源与适用边界；不是工程参数或规范认证。

开始深化前，先按任务目标列出所需图纸类型，再记录各张图的来源、年代和资料限制。将平面、立面、剖面和细部按同一对象关联，核对视图之间的信息是否相互支持。缺失、模糊或相互矛盾的表达单独列为待核验项，不能用图纸数量或页面能打开来代替完整性检查。

## 适用边界

由两份NPS建筑、工程和景观记录资料归纳的工作方法；不是对原文逐条规范的转述，也不代替中国工程规范、现场实测或厂家参数。采集日期不代表原资料出版日期。
