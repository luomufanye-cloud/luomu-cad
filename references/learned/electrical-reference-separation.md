# 电气资料先识别系统层级，再核参数

日期：2026-11-03T23:43:45+08:00

摘要：经审阅的绘图工作方法，附来源与适用边界；不是工程参数或规范认证。

电气读图先区分系统连接逻辑、空间点位与设备资料。单线或原理图用于识别电源、分配层级、设备及相互连接，不能替代设备在建筑中的实际定位。建立符号和标识的对应关系，并保留原始资料的适用系统及地域条件。电压、保护配置、导线规格、接地和设备选型未有项目或厂家依据时保持待核实，不从教程示意图自动采用。

## 适用边界

依据厂家指南中的术语和光伏系统图示进行工作流归纳，不构成电气设计、施工或安全审核，不把海外教程当作本地现行规范。
