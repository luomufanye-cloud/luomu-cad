# 源图构件身份与尺寸引用核对

日期：2026-11-06T20:09:03+08:00

摘要：经审阅的绘图工作方法，附来源与适用边界；不是工程参数或规范认证。

源图复绘先固定文件版本、视图和单位依据；块实例使用完整父子路径，保留基点、旋转、比例及镜像关系，不能只按块名或插入点替代构件。墙体的轴线、结构面和完成面分别标识；门窗的宿主、洞口边、门轴及开启侧必须对应原图证据。尺寸链绑定明确的特征身份，分段与总长同时计算，发现矛盾先查来源，不平均改墙掩盖。清点结果双向对照源图与输出，不能静默删除未知块、属性、开口或范围外信息。原图缺少门扇不产生补门依据，墙色和墙厚不证明承重。实施方法与原创模拟练习见[源图整理专题](../cad-source-intake.md)。

## 适用边界

适用于图纸输入整理、可追溯构件识读和复绘检查。两个页面来自同一软件仓库，不构成独立工程规范佐证。包围盒用于候选选择，不能证明精确几何或构件类别；尺寸检查只覆盖明确录入的特征。工程性质、安装参数和现场状态需相应专业资料。没有引入上游源码、网页组件、图纸或模型。
