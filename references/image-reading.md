# 图片识读与来源交接

日期 2026-11-07

摘要 为栅格参考建立可追溯的形状、文字、方向和连接记录，适用于平面、立面、剖面、机械零件、设备及节点等图像。区域和对象类别随实际输入选择。

## 从全图到局部

先实际查看原始附件，确认图纸范围、视图数量、方向、图例、已知尺寸和任务要求。记录源文件身份及实际像素尺寸。通过矢量 PDF 或 CAD 原文件能够取得精确对象时，沿用相应源对象提取流程。扫描页可使用已有页面渲染工具输出图片，并保留页码。

文字、尺寸、轮廓或连接在全图中难辨时，查看原像素局部。裁剪范围应包含完整目标及判断所需的邻接对象。跨块对象合并观察，覆盖、断线、交叉和连接分别记录。需要旋转或透视校正时保留原件及变换依据，先确认视图性质再处理。

使用随包工具准备通用查看材料，依赖项目已有的 Pillow。

```text
python scripts/prepare_image_regions.py reference.png --output outputs/reading
python scripts/prepare_image_regions.py reference.png --regions regions.json --output outputs/reading
```

第一条命令生成全图概览及覆盖全图的重叠区域，默认块边长 1024 像素、重叠 128 像素。可通过 `--tile-size`、`--overlap`、`--zoom` 调整。按对象划分时提供 JSON 数组，例如 `[{"id":"detail-a","box":[120,80,440,320]}]`，坐标范围依据本次源图填写。右、下边界不包含在区域内。

命令返回 `regions.json` 路径。其所在目录包含原像素裁剪、查看图、概览及哈希。路径相对于清单目录，整组可搬移。相同输入和选项使用相同目录，不同输入使用各自目录。多帧图像通过 `--frame` 指定从 0 开始的帧，默认第 0 帧。

工具按 EXIF 方向展开，透明图合成到声明的白底。所有来源坐标采用展开后的像素空间，左上为原点、X 向右、Y 向下。`view_to_source` 用于把查看图坐标乘以相应 scale 后加 offset，回算源坐标。最近邻放大保留已有像素结构，概览用于定位。必须实际调用图像查看工具读取需要判断的区域，保留工具支持的足够分辨率。

## 对象识读记录

按当前任务所需精度，为每个相关对象记录源文件哈希、页或帧、区域 ID、像素范围及以下适用内容。可以使用简短表格或 JSON，沿用已有对象 ID。

- 可见外轮廓与内轮廓，包括直线、圆弧、曲线、孔洞、分界及端点。
- 朝向和相对位置的可见依据，例如非对称轮廓、箭头、轴线、文字方向或连接端。
- 连接、间隙、相交、遮挡和重复实例差异。跨视图关系须有标号、投影或其他具体依据。
- 原文、数值、单位、符号以及尺寸界线或引线的落点。OCR 可辅助转录，尺寸小数点、正负号、直径和公差符号仍需对照原图。
- 无法确定的具体范围、可能解释及其影响。推断带来源依据，缺失信息保留状态。只有影响任务且现有资料无法消除的问题才向用户集中询问。

对象名称用于组织记录，几何取自当前参考中的可见结构。结合全图和局部检查比例、方向及连接的一致性。多张参考优先利用清晰区域交叉核实，出现冲突时保留各自来源。重复构件先比较差异再复用。

## 交给现有复绘流程

把已确认的观察转换到[源图清单](redraw-source-gate.md)，沿用其 `objects`、`source_locator`、`review_regions` 和 `raster_quality.components`。`source_locator` 可写入源哈希、帧、区域 ID 与像素范围。记录像素到模型坐标的尺度、原点、Y 方向及采用依据，使用现有 `PageTransform` 完成已确认的缩放和镜像。

独立来源记录先于输出图形建立。缺少尺度时按已有未定尺路径处理，待核实的形状继续携带不确定状态。完成某个局部的识读后，可继续该范围的后续工作。整个任务的覆盖范围按用户要求确定。

工具测试能够验证分区覆盖、坐标回算、原像素保留和可移植性。模型识读效果需要以独立参考答案核对真实输出，记录遗漏、方向错误、文字错误和连接错误。评估样例应覆盖多种图型、分辨率和复杂程度，分别报告结果。最终 CAD 仍执行已有复绘及图面检查。
