# 栅格参考复绘与交互性能检查

日期：2026-11-07

摘要：从图片中重建可辨识的构件结构，使用独立构件范围、表达预算和门的几何关系检查保存结果；把图面质量、文件完整性与实际操作体验分别记录。

## 源图坐标与表达选择

先核实是否有明确真实尺寸。有依据时校准毫米坐标并独立复核；明确只有图片且要求按图复绘时，可采用 `units=0` 和 `scale={"status":"unscaled","basis":"具体源图坐标及变换依据"}`。保持比例与相对位置，不能附加毫米尺寸或施工定尺结论。已确认没有尺寸后，不重复索要同一信息。未定尺路径不支持用原生 DIMENSION 把图片长度冒充实物测量。

墙、窗、门、家具、洁具、文字、引线和设备底色分别识读。直线、圆弧、圆角及平滑轮廓用适合的原生几何表达；不把压缩噪点、抗锯齿灰边或纹理色阶追踪成大量小面。设备底色和源图真实剖面填充可保留简单面，不能为了减少对象删除可辨识的构造。

先选能代表当前难点的区域，实际对照源图与原生/回读预览，确认位置、比例、连接和线稿表达后再批量扩展。没有明确的用户逐项审批要求时由执行者完成这一检查，不把样区检查变成额外许可流程。不能把一套通用家具块直接替换源图不同形状。

## 可执行构件检查

图片源清单声明 `source_format=image`，其余对象、表现属性和映射沿用[源图交付检查](redraw-source-gate.md)。构建器支持毫米及明确未定尺源坐标。检查器也按图片文件扩展名识别栅格输入，不能只删除 `source_format` 绕过检查。

增加 `raster_quality`：

```json
{
  "components": [{
    "id": "door-a", "object_ids": ["leaf-a", "arc-a"],
    "depiction": "linework", "source_locator": "页0门A源图区域",
    "budget_basis": "源图可辨识的一根门扇轴线及一条开启弧",
    "max_entities": 2, "max_vertices": 3,
    "source_bounds": [20, 20, 120, 120], "tolerance": 0.01
  }],
  "doors": [{
    "id": "door-a", "source_locator": "页0门A源图区域",
    "arc_id": "arc-a", "leaf_ids": ["leaf-a"],
    "hinge": [20, 20, 0], "closed_tip": [120, 20, 0],
    "open_tip": [20, 120, 0], "sweep_degrees": 90, "tolerance": 0.01
  }]
}
```

这是原创接口示例，数值不是通用尺寸或复杂度阈值。预算根据源构件可辨识结构制定，不能从错误输出的面数反填。`source_bounds` 是转换到模型坐标后的独立源范围。每个源对象恰好归属一个构件；`linework` 拒绝填充、嵌图及图块藏面，`solid_fill` 仅允许简单实心填充。复杂度检查统计对象及折线/样条/填充控制顶点，不把成块后的模型对象减少当成几何变简单。

`doors=[]` 只用于源图确实没有适用门构造的情况。门检查读取实际 ARC 的圆心、半径、起止端与扫角，并检查 LINE/LWPOLYLINE 门扇边界同时抵达源铰点及开启端。门框与两侧墙洞的接合、门扇厚度、开向和墙内交叠仍需源图对照；当前自动关系检查不宣称覆盖这些未实现条件。缺失构件或源图清单不完整不能靠哈希检查发现，必须真实识读。

## 当前图纸与关联修改

写入前核实完整路径、当前 token、未保存状态和目标对象。另存、重开或其他会话改变图纸后重新建立基线，不使用同名文件的旧记录。多个工作会话不能同时写同一活动文档；发现目标状态变化先回读再续接。

改墙/窗后检查相邻门框、门扇、柜体及标注；替换平面后检查点位、引线和图例；改共享块/样式后检查所有实际使用者。按本轮影响范围复查，保护范围外对象。用户要求原位修改时沿用原 DWG，不为内部版本管理另外创建交付图纸。

## 卡顿证据与排查

`cad_performance_snapshot(document_token)` 只读当前路径、保存状态、模型对象数及可用图形/预览变量；不选择对象、不重生成、不改设置、不保存、不重启。变量不可用时显式记录。该接口耗时不代表鼠标输入延迟。

先区分当前图特有还是多张图都卡：有现成空白/简单图且切换不打断用户工作时，按相同操作对照。没有合适对照图且未授权新建时，不擅自建图。每次只改变一个候选因素，记录原值和同一操作的前后反馈；无改善时恢复试验值。不能在没有证据时反复修改捕捉或显示偏好。图块整理应同时检查内部几何、绘制顺序和实际操作，模型空间对象数减少不证明渲染负担消失。

`workbench_assess_interaction(evidence)` 接收明确的文档路径/token、`change`、`operation`、`before`、`after`及可选 `command_seconds`。只有绑定同一文档、token和操作的 `interaction_observation`，包含 `method=user_feedback/end_to_end_measurement`、具体 `details` 和 `resolved=true`，才记录该操作恢复。用户反馈仍卡优先保留未解决；快的命令耗时不能覆盖它。此工具核查记录一致性，不能认证反馈真实性或因果关系。

重启、切换需重启的图形后端、驱动安装和全局设置变更仍遵守任务授权；连接故障不自动产生这些权限。源图一致、范围保留、原生显示、保存重开和交互性能分别报告，只能对实际检查项下结论。
