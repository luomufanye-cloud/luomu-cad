# 管根界面与完成面变化训练

日期：2026-11-05

摘要：研读既有厂家管根资料，新增自拟毫米剖面、界面缺陷与标高迁移题。保存DXF回读和图面审阅均已完成，能力状态仅为本组exercise_checked。

范围：管根界面几何、材料与工序场景练习。考核结论按各项证据记录，完整节点能力按专业学习清单评估。

## 追加的实际学习与考核

进一步读完G103产品资料第2页，并查阅厂家当前产品页和2024-03-03修改的专项技术答疑。新增14个自拟材料/工况题，覆盖基层明水、PVC处理、增强缺失、配料加水、使用时间、道间干燥、局部薄点、过早闭水、冬季排程、渗漏处理、位移工况选择和保护覆盖。它们是明确给定的学习场景；没有伪造现场测厚或闭水结果。

新增计算使用自拟24平方米、1.8毫米厚度和10%余量。按所选资料用量范围算出理论77.76—86.4千克；取上限及余量得到95.04千克，17千克包装估算6桶。单桶按资料质量比拆算液粉，并独立核对总质量。用量估算不能替代实际干膜厚度检查；模拟薄点题即使平均值足够仍判不通过。

专项技术页与产品页的可使用时间存在差异。本题采用20分钟一批、25分钟上限的自拟作业计划，落在两份说明时间内；没有把这个训练决策改写成厂家的统一技术规格。冬季题实际修改了排程，不沿用普通条件的结果。

新增证据在runtime/training/pipe-penetration/material-exercises.json。上述补学已录入技术卡。完整管根主题继续按材料/尺寸/位移/工序/检验/复绘/模拟交付清单推进，局部题数量不代替主题验收。

## 实际学习

实际读了东方雨虹2021上传白皮书的PDF36—38页文字，查看36、37页照片及说明，并对照G103产品资料第1页。原始文件及图像哈希在本地研究记录中保存；历史版次和当前有效性未确认。两份资料属于同一厂家，不能当成独立来源互证。

资料支持分别检查管壁/基层处理、接缝密封、局部增强、大面涂层与后续保护。白皮书和具体产品页的细部处理表达有差异，采用时须确定完整体系，不能组合成统一配方或节点。外观连通也不能证明实际粘结和水密合格。

本次原创训练将这些界面分层表达，并把完成面变动加入错误题。图中收头须高于完成面是本题给定约束，不作为所有管根体系的通用规范要求。

## 完成的练习

运行scripts/train_pipe_penetration.py产生五份原生DXF。所有尺寸均为自拟输入：管外径110mm，板厚120mm，基层顶20mm，初始完成面50mm，增强路径相对基层上升50mm、水平展开180mm。路径没有厚度；密封短线只标接口；未表达完整饰面、套管、锚固或防火构造。

| 题目 | 实际回读结论 |
| --- | --- |
| 正常题 | 两侧增强路径连通，顶70mm高于完成面50mm，界面标记存在 |
| 右侧路径断开 | 检出基层与管壁路径端点不相接 |
| 缺少密封界面 | 检出两侧界面标记缺失 |
| 完成面抬至80mm | 检出收头70mm被覆盖；没有沿用原题通过结论 |
| 调整后的迁移题 | 自拟上升改为80mm后，顶100mm满足本题约束 |

另完成七道解释、体系差异、工序与条件变化问答。答案由Agent按来源复核，未经过独立专业考官考核。实际查看正常和抬高完成面的离线PNG，确认图面中红色增强路径与绿色完成面的相对关系；这是示意图检查，不是施工图图册验收。

结果在runtime/training/pipe-penetration；材料和来源证据保存在runtime/learning-batches，不进入公开源码包。技术卡通过workbench_technical保存；通用来源核对方法已存在，不重复晋升workflow。

## 适用边界与下一题

能解释本组管根界面、复绘自拟剖面并找出指定缺陷。还需补真实批准体系的膜厚、增强材料、背衬/密封几何、位移能力、养护与试验条件。地漏法兰、套管封堵及结构孔洞需要各自节点，下一题补地漏排水口/防水层接口与坡向，不用管根示意替代。
