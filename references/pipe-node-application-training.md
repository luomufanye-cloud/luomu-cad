# 管口材料分支与节点应用训练

日期：2026-11-07

摘要：结合正式安装手册与产品说明，将管口密封、工况变化、搭接、完成面和检验组织为同一套应用练习。输出包含参数、平剖面、原生尺寸、计算和错误诊断；数值采用条件与工程实测分别管理。

## 原文与关键图核对

本次研读美国厂家[安装手册](https://assets.schluter.com/asset/570120892212/document_i2tt9fh4sp2n562jmirhppbv4o/shower-system-installation-handbook.pdf%3Fcontent-disposition%3Dinline)，封底版本04/2026；选读PDF第17、19、22、35页，并查看第22页安装图。该图显示密封接口位于膜面穿出部位，不能从照片量取胶缝宽深。另读[管封产品说明](https://www.schluter.com/schluter-us/en_US/Shower-System/Waterproofing/Schluter-KERDI-SEAL-PS--MV/p/KMSMV235-114)和[密封材料说明](https://www.schluter.com/schluter-us/en_US/Shower-System/Waterproofing/Schluter-KERDI-FIX/p/KERDI_FIX)。访问日期均为2026-11-07，文件及关键图哈希保存在本地证据中，原文原图不随包分发。

| 条件 | 采用与检查 |
| --- | --- |
| 普通非蒸汽淋浴穿膜点 | 按第22页，可采用配套管封或适合的密封材料；使用FIX时清除粘结面污染，压实膜材并排除空隙。产品说明中的“多种塑料”不能推导成全部塑料适配。 |
| 间歇蒸汽入口 | 第17页明确排除FIX；可选PS、RTV或其他适合的密封材料，并继续核对实际管体、温度和安装条件。 |
| 连续蒸汽入口 | 第19页排除FIX，入口条款列出RTV或其他适合材料；不能把上一行的PS选项直接移入。房间防水体系还应按该章采用DS。 |
| 临时堵头、保温外壳、可拆饰盖 | 均不能未经设计成为永久防水终点。归纳的检查路径为：大面膜→连续接口→已确定的永久管体。拆换后复核接口完整性。 |

同一资料内的一般穿透说明不能覆盖特定蒸汽入口的限制。工程采用需对应地区、用途、产品版本和实际受力条件。

再次实际查看既有[系统数据表](https://assets.schluter.com/asset/570120892212/document_2nqfpg0pi13itfso529nhmlr7f/Shower%20System%20Data%20Sheet.pdf?content-disposition=inline)PDF第13页，发现PS/MV表中的英寸与厘米写法不一致，原图本身存在该问题，并非仅文字提取错误。因此不将其公制值直接用于选型。目录开口、公称管径、实际外径、法兰外径必须分别识读；也不能按型号数字反推尺寸。现有原文没有给出通用的PS允许管外径区间。

## 完整输入的模拟交付

运行 `python scripts/train_pipe_node.py`，输入为 [原创训练参数](../examples/pipe-node-training.json)。训练以普通非蒸汽、固定金属管的膜面密封路线组织几何；板厚、粘结层、管径、孔径、环隙和突出余量均为明确的自拟条件。0.2032mm来自8mil换算。模拟胶缝几何不构成厂家宽深规定或实际材料认证。

交付包含平面及剖面DXF、原生DIMENSION、PNG、输入和回读报告。实际读取保存后的图元、单位、层次、尺寸倍率及平剖对应；不从输入JSON直接宣称图纸正确。说明题另行作答与评阅，程序结果只覆盖实际执行的几何和计算检查。

| 条件变化 | 独立计算与处理 |
| --- | --- |
| 125mm带、8mm缝、偏移12mm，训练要求每侧50mm | 有效覆盖为46.5/70.5mm，失败；偏移改8mm得到50.5/66.5mm。若采用严格2in=50.8mm，允许偏移从8.5mm变为7.7mm，不能混用阈值。 |
| 管外径32mm、孔径44mm、偏心3mm | 最小环隙3mm，小于自拟4mm目标；孔径改46mm后为4mm。该目标只作本题尺寸约束。 |
| 原完成面28.2032mm、管端55mm；饰面增厚8mm | 突出量从26.7968降到18.7968mm，小于自拟20mm目标；将模拟管端改65mm后为28.7968mm。实际管件不得据此擅自加长。 |
| 缺一侧连接、连接埋在基层 | 即使两端尺寸正确，膜面防水路径仍断开；检查器通过保存后的连接位置识别。 |

另有八道独立应用题覆盖目录、永久密封对象、换管材与蒸汽、搭接、低温养护、漏水修复、位移及成套交付。初次作答遗漏蒸汽入口的明确分支，按原文纠正后复评。答案示例、实际答题评阅和现场试验分开记录，未将固定答案列表计入考核通过数。

## 施工、检验与修复

原创控制流程为：固定工况和永久对象→核对基层与材料→确定接口尺寸与位移条件→处理基层和粘结面→完成膜面连续连接→检查空隙与接缝→按相应材料养护→检验→修复复验→饰面保护。工作位移和断裂伸长、表干和深部固化应分别判断。

室温模拟题在7日09:00完成粘结，采用24h等待及另行给定的24h观察，则8日09:00开始、9日09:00结束。低温不能直接沿用排程，也不能自造延长系数；需先满足所选材料的施工及养护条件。厂家一般等待说明不能取代地方检验要求。

水位下降先区分堵头、蒸发及接口失水，记录水位、时间和试验条件。破口距管口仅40mm而无法形成规定膜间搭接时，应重建连续接口，不能在饰盖处补胶掩盖。修复后的等待从相关新粘结完成重新计算，并重复适用检验。
