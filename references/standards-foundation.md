# CAD标准基础与交付依据

日期：2026-11-07

摘要：将适用标准作为绘图和交付的基础。先确定行业、地区、阶段及用途，再核实版本、读取条文并映射到检查证据。索引、条文研读、图纸检查和专业批准分别记录。

## 开工与交付流程

1. 确定所在地、专业、阶段、交付用途、合同体系及设计/复绘权限。参考复绘发现源图不规范时记录差异，不擅改设计，交付结论限定为源图忠实度。
2. 用 `workbench_standards(operation="route", discipline="…")` 查[标准索引](standards-catalogue.json)。现有43条标准记录、20条专业路线是查证基础，不代表全行业所有规范已收齐。
3. 向发布机关或官方目录核实标准号、年份、实施日、修改单、替代关系及过渡规定，同时核对地方标准、合同/业主规范、设计文件深度和专业接口。旧书、题录及新版草案不能证明当前版本。
4. 合法取得适用条文，记录条号/页码、要求、条件和采用理由，再对应实际对象/视图、检查方法、接受条件、证据、结果及未解决项。未读正文不填“符合条文”。
5. 交付前检查标准依据记录，再结合现有几何、图面、文件与范围保护检查。一个制图标准不能证明结构、消防、电气或制造工艺全部合格。

解释资料、环境安装和原创软件训练不冒充项目交付，不因此安装全部行业依赖或连接CAD。实际绘图开工选标，最终交付必须有本项目标准依据记录。

## 四层基础

| 层 | 需要核对 | 边界 |
| --- | --- | --- |
| 通用/专业制图 `drawing` | 图幅图框、投影、图线、字体、比例、尺寸、符号及专业表达 | 按行业选择，不能把建筑规则套到机械或船体 |
| 专业设计 `design` | 材料、荷载、计算、构造、设备、消防及专业接口 | 图画得像不证明设计合理 |
| 制造/施工与验收 `construction_acceptance` | 工序、材料批次、安装/制造、实测、检验与试验 | 按行业选择制造、产品或施工验收要求；不由图纸检查代替 |
| 数据与文件交付 `data_delivery` | 图号版次、命名、外参字体、格式、齐套、签署、更改及模型数据 | 普通DWG不自动成为BIM交付 |

每层说明“覆盖/不适用/未评估”及原因。参考复绘可保留未评估层为限制；提出规范复核结论时不得留空或算通过。强制要求、专业标准、地方要求与合同有冲突时查明正式适用和过渡条件，不能选择更容易通过的一份；实质冲突未解决时不交付合格结论。

## 来源与版本规则

- 公告/官方目录核实身份、实施和替代，正文核实条文。推荐性标准在项目中的约束还要看正式采用情况，不能只看编号认定全部强制或均可忽略。
- [国家全文公开系统](https://openstd.samr.gov.cn/)说明工程建设国家标准另查相关部委；部分采标全文受版权限制。没有正文时记录“元数据已核、正文待取得”，继续查发布机关、出版社或授权数据库，不绕过登录和付费。
- [国家标准馆](https://www.cnis.ac.cn/ynbm/gjbzg/bzhfwdy/201901/t20190102_35623.html)提供题录、阅览和跟踪入口。[知网入口](https://kns.cnki.net/kns8s/)本轮返回502，未取得其标准全文，不把数据库介绍当已读正文。
- 教材/图集用于解释和练习，保留版次/ISBN/图号。[清华大学出版社《机械制图》第4版](https://www.tup.tsinghua.edu.cn/upload/books/yz/088619-01.pdf)为2020版，其历史“最新标准”简介不能确认2026年状态。
- [水利部门转载的2026年公告](https://www.hengyang.gov.cn/hysslj/xxgk/gzdt/bsyw/20260128/i3855455.html)列有SL/T 73新版和实施日，旧目录仍可能显示旧版现行。索引保留差异，项目回到正式公告与正文核实。
- ISO/DIS是草案，其替代措辞不等于正式新版已生效；ASME的R2024是重申标识，译本发布日期也不等于原标准升版。

## 已实际研读的基础条文

已从[住建部正式公告](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2018/art_17339_234638.html)取得GB/T 50001-2017官方附件并查看范围、术语、目录和以下选页。原PDF仅存私人研究目录，不公开扫描全文。下表是有限原创归纳，不替代正文及条件。

| 条文及印刷页 | 归纳 | 对接检查 |
| --- | --- | --- |
| 3.1.1，页5 | 图幅与图框对应 | 实际纸张边界 |
| 4.0.1～4.0.2，页13 | 线宽成组、用途分明 | 图层实体打印覆盖 |
| 5.0.1～5.0.5，页15 | 字体清晰、字高字宽有据 | 文字与纸面尺寸 |
| 6.0.1～6.0.6，页17 | 实物尺寸与图样比例分开 | 模型视口打印倍率 |
| 11.1.1～11.1.4，页43 | 尺寸组成及线的关系完整 | 定义点与显示 |
| 12.1～12.3，页55 | 模型与图纸文件分别管理 | 实际尺度、命名用途 |
| 14.0.1，页63 | 方向、轴网、指北针协调 | 视图相互对应 |

具体阈值和条件按项目逐条建立，已阅读不等于已实现全部自动检查。现有工具可辅助图框、样式、尺寸及文件回读；专业解释、整图和计算未覆盖项继续审查。

## 可执行交付记录

使用[未填写模板](../examples/standards-basis-template.json)，模板未知项会被拒绝。

```text
python scripts/verify_standards.py drawing.dxf project-standards.json --report standards-report.json
python scripts/verify_redraw.py drawing.dxf mapping.json --reference-inventory source-inventory.json --source original.pdf --review review.json --standards-manifest project-standards.json --report delivery.json
```

记录绑定最终图纸SHA256，包括项目条件、四层适用性、标准号年份、版本来源/查证日/实施日、条文阅读等级、检查结果、证据及未解决项。证据路径相对记录目录且限制在内部，使用SHA256及drawing_sha256绑定当前图纸。仅题录不能填条文通过；失败、未检查、过期图纸、被替代版本和无合同依据的跨体系采用不能通过对应检查。

`reference_only`加`compliance_claim=false`仅支持忠实复绘限定结论，保留未评估的工程要求；不擅改源图。`drawing_review/engineering_review`要求采用标准已读条文、有实际证据并明确四层结果。历史标准仅用于历史复绘，不能作为当前新设计合规依据。

检查器只核对声明记录、版本和证据绑定，不认证来源真实性、条文解释、全条文覆盖或专业签署；`standards_compliance_certified`与`engineering_approval`始终为false。工程审查、签署和现场验收按实际任务独立办理。
