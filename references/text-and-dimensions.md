# 中文显示与尺寸界线

日期：2026-11-06

摘要：分别验证文字内容、字体映射和宿主显示；尺寸界线按纸面尺度控制长度与留白，保留原测量定义。适用于新建参数图及获得授权的标注局改。

## 中文与符号

1. 回读已保存文件及活动 CAD 中的原生文字。若中文已变成问号或替换字符，从可核对原文恢复，不靠换字体猜字。若 Unicode 内容完整而显示问号，检查文字样式、字体替代、MTEXT 行内字体及块内文字。
2. TrueType 样式同时设置字体文件与字体族信息。仅写 `simsun.ttc` 等文件名，或在离线预览中能显示，不能证明 AutoCAD 已正确解析字体。使用 `luomu_cad.annotations.configure_cjk_style(doc, style_name)` 配置明确指定的样式；不全局替换其他样式，不改变单位或文字内容。
3. DXF 保存字体文件名和字体族；不打包系统字体或写入发布者本机路径。目标设备必须安装相应字体。跨平台缺少字体时选择目标环境实际可用且覆盖所需字符的字体，记录替代，不宣称显示已验证。
4. 活动 AutoCAD 通过 MCP 服务端修改 `TextStyle.FontFile` 和 `SetFont`，再更新使用该样式的实体并 Regen。保留对齐点和 MTEXT 格式。空 BigFontFile 在部分版本的 ActiveX 中拒绝赋值，已经为空时不重复写空值。
5. 查看宿主原生预览中的中文、乘号、面积符号、直径及正负号，同时检查换字体后的文字宽度、表格越界及邻接标注。原生 DIMENSION 不自动意味着已建立与墙体的关联；实际验证更新行为后才报告关联可用。

## 尺寸线、尺寸界线与留白

尺寸线表示测量范围，尺寸界线从被测点朝尺寸线引出，轴线是另一种对象。不要为缩短界线修改测量定义点、伪造数字、炸开标注或删除轴线。

- 新建图需要短界线时，使用 `short_extensions(scale, length=3, gap=1.5, beyond=1)`。参数是纸面毫米，经一次换算得到模型毫米，DIMSCALE 为 1。3/1.5/1 mm 是可调整的呈现选择，不是所有专业的强制规范。复绘优先原图表达，明确要求调整时再采用。
- `DIMFXLON=1` 启用固定长度；`DIMFXL` 控制从尺寸线朝被测点方向的长度，`DIMEXE` 控制另一侧超出量，`DIMEXO` 控制测量起点处最小偏移。不能只调 DIMEXE 期望整条长界线缩短。
- 例如 1:100 的上述选择为 DIMFXL=300、DIMEXO=150、DIMEXE=100，均为模型毫米。核对实体覆盖及 DIMSTYLE，重生成显示块，回读测量值不变，并检查实际线段。
- 尺寸链位置另按实际外包轮廓安排：包括阳台、飘窗、轴号及已有标注。固定界线并不自动解决尺寸链离建筑太近、太远或与轴号碰撞的问题。分别检查各道链间距、墙体净空和短尺寸文字避让。
- 水平/竖向尺寸的定义点应对应实际被测位置；不能为编程方便把全部标注投到世界原点，再让界线跨过整栋建筑。
- 不直接沿用库内置 DIMSTYLE 的测量倍率。毫米实尺新图核对 DIMLFAC=1，正常尺寸使用自动测量文字；尺寸定义正确但 DIMLFAC=100、再用固定数字覆盖，同样判为失败。比例不同的详图按其已核实变换另行判断。
- 局改保留最新对象、前次修正和所有范围外构件；原文件备份。字体变更引起对齐文字边界变化时检查其锚点和排版，不把正常字宽变化当作墙体改动。

## 可执行检查

复绘的verify_redraw.py已经强制调用中文内容与字体映射检查。完整交付另需[源清单和当前图面对照记录](redraw-source-gate.md)，不能只运行下述单项检查后称整图通过。

```text
python scripts/check_annotations.py drawing.dxf --max-extension 300 --min-gap 150 --report annotations.json
```

限值是本次采用的模型毫米；不得对全部比例直接照抄。检查可拦截缺少中文字体族映射、可疑损坏文字、未启用短界线及偏移不足。它不读取宿主字体缓存，不证明墙体净空或完整图面正确；仍须实际查看原生预览。普通 Python 渲染器自动替代字体不能算宿主显示验收。
