# 0.15 制图与独立验收验证记录

日期：2026-11-08

摘要：本版完成原生DWG回读、实际纸面笔重检查和独立审查执行入口，并保留真实拒绝结果。以下结果各自限定测试对象，不构成全行业工程或图片识读认证。

## 实际完成范围

- 本地完整回归892项通过、18项跳过；跳过项目不算完成。
- 固定参数原生制图测试采用5000×4000毫米墙轴、200墙厚、900单扇门、1800窗、2100×900沙发及1100×600椭圆茶几，包含4个原生尺寸和中文标题。
- 通过真实stdio MCP完成保存、关闭和相同SHA的重开。独立审查核对54个模型实体及37个尺寸显示块实体；墙体与独立任务坐标基准的面积对称差为0，门窗洞口、铰点和家具位置符合本次任务。
- 实际A3横向PDF按固定窗口和1:25输出。独立逐段检查全部61个描边：2个墙体描边为0.25毫米，其余59个为0.13毫米，包括逐条定位的12段尺寸线及延伸线。同一活动MCP服务的最终文件检查通过全部5项原始需求。
- 真实旧输出中的12段尺寸线错误保留为拒绝对照；修复采用本单图层及显式覆盖，未将某个行业笔重设为所有行业默认。合法DXF零线宽声明也保留。
- 固定1000×600毫米DXF及A4 PDF任务已完成真实独立CLI模型审查并通过原合同最终检查。原始文件、实际MCP读取、图像查看、模型会话和结果均有本机执行记录。

## 默认独立审查的实测结果

`workbench_review_agent` 提供prepare/start/status。原始任务、全部格式、源文件和标准依据不从生成者报告提取；后台执行真实独立模型并校验读取、图像访问及逐需求关联。

原生DWG绑定证据的真实模型运行完成12次成功读取/图像查看，覆盖6份授权材料和3幅图面。该模型接受DXF—PDF纸面对应，但对原生部分要求原生导出图及本轮活动复验，给出拒绝。此拒绝完整保留，本版未修改模型结果，也不声称默认原生模型验收已全项通过。本项目允许按完整原生回读数据离线渲染；对此方法与独立模型审查阶段的解释仍需后续统一，不能靠填写通过字段解决。

另一次父stdio退出的实测中，宿主清理终止了后台进程。现已补进程创建标识和异常退出检测，持久记录failed且不自动重启。实际运行应保持所属MCP连接至审查完成，可由另一会话查询；detached不保证抵抗宿主整树清理。

## 边界与交付要求

原生检查目前限正WCS XY二维基础图元、普通线性/对齐尺寸及连续线型；未知对象拒绝。完整对应PNG是原生数据逐项对应后的离线渲染，PDF为实际原始DXF的矢量输出，均不冒称AutoCAD原生Plot。

28类行业分类、103个行业限定图种及标准白名单用于选路与隔离，不能证明已读全部条文、完成各行业计算或能交付任意工程。上述明确参数测试不是从客户图片自动识读，不证明真实图片准确率提高。工程审核、法定审签和客户签收仍按实际项目办理。
