# Luomu CAD 0.16.0 发布说明与验证范围

日期：2026-11-14

摘要：将此前分支上的多模型独立审查、共享 CAD 任务协调和状态比较正式纳入 0.16.0，统一主分支、首页、运行版本、锁文件及下载包。保留 0.15.0 原生文件交付检查，不声明客户工程图因此自动合格。

## 本版更新

- CodeBuddy 项目级及个人作用域 `luomu-cad-reviewer`，原生子代理继承当前模型。后台作业支持 CodeBuddy，Codex 后台也可显式传递当前会话模型；请求绑定宿主与模型，重复请求不重复启动。
- 只读证据服务的原件哈希、实际读取记录、图像与结构化结果继续校验。模型输出或工具成功不能替代逐需求原件检查。
- 通用 MCP 接入协作式任务占用，分别记录编辑、切图、保存、关闭、导出授权；新明确指令通过当前修订更新，进程退出后 OS 锁释放。
- 记录状态比较会指出实体数、文档身份、快照指纹及已知保存状态差异；相同计数不足以证明未变。比较工具本身不连接 CAD，也不签发交付通过。
- 固化近期学校多页 A3 换框、参考复绘、局部修改及纯设计任务的工作流经验。

## 已有实际验证

- 功能基线全量回归：933 项通过、18 项按环境跳过；Windows、Linux 分支 CI 均成功。
- HY4、HY3、DeepSeek、GLM 真实启动原生审查子代理并核对模型继承；HY4、GLM 完成后台证据审查，GLM 包含真实 stdio MCP 异步作业和重复请求核对。
- 新任务协调具有跨进程占用、退出释放、分项授权与修订冲突测试；真实 stdio MCP 回放了归档的 2166→2161 实体状态变化，返回过期而非放行。
- 发布准备增加运行模块、pyproject、uv.lock 与首页版本一致性检查。正式发布工作流在最终提交双平台检查通过后构建两种包，执行隔离源码安装回归及 WorkBuddy 安装/任务检查，再创建版本与附件；具体运行结果见 GitHub Actions。

## 使用范围

协作占用只协调接入同一目录的 MCP 服务，不能锁定 AutoCAD 界面，也不自动改造旧专用适配器。状态比较只比较传入记录，最终仍须实际 MCP 回读和原合同检查。未逐个实测全部模型，不把行业分类、软件测试、固定参数制图或发布成功称为全行业工程验收、图片识读准确率提升或模型权重训练。
