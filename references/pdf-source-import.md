# 矢量 PDF 的测量提取与可编辑复绘

日期：2026-11-07

摘要：从原 PDF 页面读取路径、字形位置和显示属性，建立来源清单，再交给统一复绘构建器。原始页面保持只读；提取过程不设计布局、不添加家具、不凭图名或标题栏猜定尺。

## 执行顺序

1. 在原图选择一段有明确实际尺寸的基线及另一方向的独立复核线，记录各自端点和实际毫米长度。端点使用 PDF 原生用户坐标，原点在左下方、Y 向上；使用上方原点的读取工具时先转换坐标。页面旋转由提取器处理，不能自行重复旋转。
2. 调用 `workbench_pdf_inventory`，传入文件、页码、校准数据和明确的字体映射。提取器保留源文件哈希、页码、对象路径、字体文件哈希、转换结果及具体异常。
3. `ok=true` 且 `inventory.extraction_complete=true` 后，使用同一来源文件与生成的清单调用 `workbench_redraw`。任何未完成提取的清单都会被构建器拒绝；不得手工把该字段改为通过。
4. 回读保存的 DXF，对照原图检查全页、文字、曲线、填充及裁剪区域。使用相同纸张、窗口和背景进行视觉比较；几何清单通过不代替这一步。原图尺寸标注的语义核对仍按 [忠实复绘](faithful-redraw.md) 执行。

`calibration` 必须包含以下字段：

```json
{
  "source_points": [[20, 20], [100, 20]],
  "distance_mm": 800,
  "check_points": [[20, 20], [20, 120]],
  "check_distance_mm": 1000,
  "tolerance_mm": 0.1
}
```

这些数值仅演示一个具有完整给定条件的训练输入。实际图纸必须使用该图的测量依据。复核线方向须与定尺线不同；复核长度不一致时返回 `CALIBRATION_CONFLICT`，不得平均两种比例掩盖冲突。

`font_map` 将 PDF 字体名称映射到运行环境中确实存在的 TTF、OTF 或 TTC 文件。先依据返回的字体清单选择字体，再确认该字体包含所需字形。源 PDF 中的嵌入字体不会被导出、打包或再分发。

## 已实现的表达

- 路径保留原生坐标变换和页面旋转；嵌套 Form 的矩阵按包含关系组合一次。直线段、连续直线、三次 Bézier 分别生成 LINE、LWPOLYLINE、带原控制点及结点的 SPLINE。
- 多边形实心填充根据奇偶规则或非零绕组规则求取实际填充区域，保留孔洞，不将每个子路径单独实填，也不额外添加轮廓线。填充与描边保持原页面绘制顺序。
- 读取颜色、透明度及实际笔宽。PDF 的零宽线保留为 DXF 零线宽；其他宽度映射到可表示的 DXF 线宽，超过允许偏差时明确报错。
- 文字使用实际字形墨迹范围及源位置测量字高、字宽和方向，不把 PDF 的 em 字号直接当作 CAD 字高。每个可见字形生成可编辑 TEXT，保留 TJ 字距和局部位移；这会产生多个字符实体，而不是擅自重新排版成一段文字。字体文件名和字体族同时写入样式。
- 页面 CropBox 与单区域多边形裁剪参与转换。需要裁剪的对象保留在原生块中并配置 XCLIP；被裁掉的一部分文字仍以 TEXT 存在于块内，不用白色遮罩或删字替代。凹多边形、穿越裁剪缺口的线及边界上半宽笔画均经过检查。审计会核对裁剪开关、边界、块变换和块内对象，关闭裁剪不能通过验收。离线 PDF 输出还会裁剪最终绘制的笔画，避免只裁中心线却将半条线宽画回边界外。

## 尺寸与适用范围

PDF 的线、箭头和数字通常没有 CAD 的 DIMENSION 语义。该模块保留这些图形的实际表达，不会把相邻数字自动认作测量值，也不会宣称所有标注已恢复为原生尺寸。要求原生尺寸时，应根据原图确认界线端点、尺寸方向、尺寸线位置、标注样式及显示内容，补入独立尺寸清单，并检查替换范围。

目前明确返回异常的内容包括：栅格图片、渐变、非普通混合模式、软蒙版、透明混合组、套印、虚线模式、曲线填充边界、含孔或分离区域的裁剪、斜切或镜像文字、无法映射的 Unicode、缺失字体及非默认笔帽/接角。异常包含对应页码和对象路径；不得把局部提取结果命名为完整复绘。

PDFium 的字形读取、路径解析及源页面渲染均由外部依赖提供。提取器内部串行使用 PDFium，避免其非线程安全接口并发调用。单文件限制 100 MiB，默认限制 50,000 个来源对象及输出对象；超限要先按页面和视图拆分工作，不能静默截断。

## 验证

`tests/test_pdf_source.py` 使用项目自行生成的 PDF，覆盖定尺冲突、独立方向复核、Bézier 控制点、嵌套矩阵、填充孔洞、字体墨迹、旋转与 TJ 间距、页面裁剪、凹形裁剪、原生文字裁切和异常内容。裁剪测试实际经过 DXF 渲染流水线，并检查删除裁剪后的错误能否被拦截。私有原始资料和实机运行产物不属于公开测试素材。
