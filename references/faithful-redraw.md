# 忠实复绘与标注验收

日期：2026-11-06

摘要：适用于有参考的CAD复绘及后续局部修改。将真实尺度、内容忠实、可编辑对象和图面表达分别验收；不把矢量提取成功当作图纸完成。

## 建立参考基线

1. 明确源文件、页码、目标视图和保留范围，保存源文件哈希。一层、标准层及其他视图按原题名识别。一个视图内的尺寸、图名、比例说明和图例默认属于该视图，不能按固定窗口顺手裁掉。
2. 在绘制前依据参考列出构件、文字、尺寸链和关键坐标清单。生成器自身输出不能充当独立真值。分别记录有依据的尺寸与尚不能读取的内容；先恢复原文、矢量或更清晰输入，不能猜尺寸或自选标准件。
3. 用明确尺寸校准坐标，另一方向及未参与拟合的尺寸独立检查。模型真实单位、PDF缩放、详图倍率和出图比例分开处理。读图误差不等于工程公差；模型以毫米作图不等于整幅复刻正确。
4. 先检查PDF的线、曲线、文字、填充及裁剪。颜色和线宽只能辅助分类，同色同宽对象仍可能分别是墙、标注或家具。保留源片段与CAD对象的对应关系。

## 重建CAD语义

- 标注采用DIMENSION；按尺寸界线定位被测端点，检查测量值、线性倍率、显示精度、前后缀和文字覆盖。禁止用固定数字掩盖几何错误。使用原生对象也不自动证明与墙体关联；局改后须重生成并回读，实际测试过自动跟随才声明关联。
- 不以任意经验系数统一缩小文字。核对原参考中的字体、对齐、旋转、纸面字高和密集区域。PDF的Y轴翻转时，文本方向也应做同一坐标变换。
- 门弧、圆角、轴线及闭合轮廓分别保留几何特性。曲线转换按可说明的误差上限选择解析曲线或采样；不能对所有曲线固定取若干点后称无损。
- 不用线段包围盒作为去重身份：两条相交对角线有相同包围盒但不是同一条线。不得未经范围授权清理原有构件或重复表达。

## 制图表达与规范适用

复绘按参考表达，标准化改图须另有对应任务范围。项目已有模板/标注样式优先读取；若需规范符合性声明，核实专业、地区、标准名称、版本及具体条文，不能将任意默认线宽和字高称为通用规范。原图与适用标准存在冲突时保留问题位置并提出明确改法，不暗改原设计。

逐项检查：尺寸起止点、尺寸界线伸出与间距、尺寸线与界线线型/线宽、箭头或建筑斜短线、文字位置/方向/单位/精度、尺寸链闭合、总尺寸与分尺寸、叠压和漏标。尺寸线不得因与墙同色就继承墙线宽；轴线和尺寸线不得混为同一虚线层。模型字高、注释比例、视口比例和打印样式一起决定纸面效果。

图纸检查表还需覆盖墙与门窗开口、门向、图层线宽、剖切/索引符号、材料填充及图名。全图、尺寸密集区和关键节点分别查看。未经查看的区域不能记作视觉通过。

## 修改保持

记录当前文件哈希或活动文档token、最新实体及本轮对象列表。从当前成果增量修改；范围外实体、文字、图层和共享样式不得悄悄变化。改共享样式时检查其全部使用者。修一处后复查该处、邻接对象和既有修正；保存旧成果，不重放旧生成器覆盖当前编辑。

## 可执行检查

`python scripts/verify_redraw.py drawing.dxf contract.json --report report.json`

契约格式示例（数值为自拟测试输入，须换成本单参考证据）：

```json
{
  "units": 4,
  "source": "参考页码及哈希",
  "dimensions": [
    {"handle": "目标尺寸句柄", "start": [0, 0, 0], "end": [3000, 0, 0],
     "measurement": 3000, "tolerance": 0.1, "dimlfac": 1}
  ],
  "texts": ["一层平面图", "1:100"],
  "preserve": {}
}
```

`dimensions`是参考要求的线性标注清单，不是从输出反推的数量。handle由源对象映射定位；支持DXF线性/对齐尺寸的定义点检查，不支持的尺寸种类明确失败。`preserve`可传入修改前范围外对象的句柄到SHA256指纹映射，指纹由脚本的`fingerprints()`生成；它还比较图层、文字样式、尺寸样式及非匿名块定义，发现共享样式变化必须另行验收。文字清单按精确内容检查。无尺寸的参考可传空列表，但不能对有尺寸的参考这样规避检查。

输出`checks_passed`仅表示这些结构项通过；`reference_visual_review`和`engineering_review`不会被脚本冒充完成。此检查不能自动识别遗漏的参考构件，也不能强制宿主模型调用它。发布前用原生标注正常例、静态标注反例、固定数字覆盖、错误端点、漏文字及越界修改分别验证。
