# CAD参考图读取与核对

日期：2026-11-06

摘要：把源图单位、视图范围、构件实例和尺寸引用变成可追溯证据，服务于忠实复绘。图形识别候选不能自动成为结构判断或设计修改。

这里的“源图”是作为依据的原始图纸；“套块”指一个CAD图块内部还包含其他图块，例如一组桌椅中有桌块和多个椅块；“尺寸链”是连续的分段尺寸及它们对应的总尺寸。本专题说明如何读取这些信息，并检查复绘是否遗漏构件或量错位置。

## 文件与构件

1. 固定源文件SHA256、版本及目标模型空间视图；布局空间、外参和其他平面分别登记。裁图选择目标，不删除范围外资料。
2. 读取`$INSUNITS`并与可靠标注交叉核对。无单位时明确换算与依据。长度显示格式、公制填充设置或DXF扩展名都不能单独证明几何单位。
3. 保留WCS坐标与向上Y轴；预览的向下Y轴单独变换。套块按每一级基点、插入点、旋转和比例复合变换。块单位不同不再额外乘一次：实际插入比例已经表达变换，重复换算会使构件失真。
4. 清点实例路径而非只数块名。同名邻近块不能凭距离去重；负比例、镜像、匿名块、属性和块中直接线段都须保留。非均匀比例下圆可能变为椭圆。
5. 按包围盒相交选候选，不只看插入点或端点是否在框内。框外插入的块和两端在框外的线都可能进入视图。文字框与曲线包围盒不是精确相交证明，边界候选继续查看。
6. 建立“源图对象→输出对象”与反向清单，解释遗漏、增加、重复和合并。轮廓、填充、属性可以组成构件，但不能丢失实例数量。盘点工具提供路径与范围，语义映射仍需对照原图建立。

## 墙、开口和设备

- **墙体**：轴线、结构面、完成面分别记录，检查厚度变化与单侧齐平。柜体线、窗框不能凑成墙厚；原始、拆除、新建、预留按图例与文字确认。颜色、填充、厚度不足以判断承重，须核对结构资料。
- **开口**：记录宿主墙、洞口两边、编号、门轴、扇宽、弧线和开启侧。镜像后复核开向；只有空洞时不能按房间功能补门。编号含义按本套图例和表格解释，不默认编号数字必然等于施工尺寸。
- **构件**：桌椅组合、洁具、柜体、井道、立管与设备先登记实例，再凭图例分类。旋转矩形的轴向外框不等于自身宽深；没有朝向证据时不凭相邻家具推断。
- **协调**：水、电、暖通符号需对应图例、设备表和系统图。图形清点不能推出负荷、导线截面、流量或安装高度，采用条件与计算在对应专业内核对。

## 尺寸链查错

每个测量特征有独立ID、坐标方向、引用类型及源图位置。轴线用`axis`、墙面用`face`、洞口边用`opening`；同坐标的不同语义也分别建ID。不能用“最近一条线”替代实际测量对象。

声明链中依次连接的ID、分段长度及本任务误差限。坐标从保存DXF回读，不从目标数值反向制造验收输入。工具逐段检查，并对相同端点的累计总长查冲突；不能平均分摊矛盾或默认细部标注永远优先。混合引用可拆成同语义短链，整体关系另行核对。

模拟A/B/C轴在0、3000、7000毫米：分段3000与4000，总长7000。B轴误移120毫米后总长不变，但分段成为3120与3880，必须定位两段错误。总长若另写7100属于依据冲突，不能改墙掩盖。误用距B轴100毫米的墙面属于引用错误，不能靠放大公差通过。

链检查通过后，继续按[忠实复绘](faithful-redraw.md)查原生DIMENSION、倍率、覆盖文字、实际定义点，按[文字与界线](text-and-dimensions.md)查字形、轮廓间距和密集区域。

## MCP工具与输入

`workbench_source_inventory`只读Skill根目录内的DXF工作副本；可放在`runtime/inputs`，不进入公开资源。示例：

```json
{"path":"runtime/inputs/plan.dxf","box_mm":[0,0,12000,9000]}
```

返回源文件哈希、单位依据、套块矩阵、实例路径、原始文字、有效图层、毫米包围盒和候选选择。无单位文件补`unit_mm`与`unit_reason`。不会修文字、改单位、改图层或炸块。文档声明仍须与外部尺度证据核对。

范围为模型空间。未支持实体、外参、循环套块及几何错误列入`issues`，`ok=false`；空选择不能成功。原生尺寸、填充和其他未支持类型须接对应读取器继续盘点，当前清单不能冒充全图完整清单。文字框为字体估计，未证明宿主实际字形。默认上限50MB、20000次实体遍历、套块深度16，超限停止并保留源图。

`workbench_dimension_chains`参数示例：

```json
{
  "features":[
    {"id":"A","kind":"axis","axis":"x","coordinate_mm":0},
    {"id":"B","kind":"axis","axis":"x","coordinate_mm":3000}
  ],
  "chains":[
    {"id":"AB","kind":"axis","axis":"x","features":["A","B"],"segments_mm":[3000],"tolerance_mm":0.01}
  ]
}
```

误差限是自拟训练输入，不是工程规范公差。工具只检查声明坐标关系；未录入对象、斜向尺寸、标高、图面和项目适用性另行核对。

## 练习与判定

`python scripts/verify_source_intake.py`生成原创模拟DXF，经真实stdio MCP读取，覆盖米到毫米、非零基点、旋转镜像、两层套块、轴线误移、墙面误替、总尺寸冲突及无单位输入。保存后回读再生成预览，源文件SHA256不变。结果在`runtime/verification/source-intake`，不进公开包。

| 题目 | 解释与判定 |
| --- | --- |
| 无单位图中7单位是否就是7毫米？ | 不能确定；训练给定7000毫米总跨后采用1000毫米/单位并保存依据。 |
| 套块含非零基点和镜像，仅插入点够吗？ | 不够；复合完整变换。训练首个构件外框为1600/1400至2000/2000毫米。 |
| 两个邻近同名构件能自动去重吗？ | 保留独立实例，先证明重复。 |
| 总长正确能证明中间轴线正确吗？ | 不能；分段检查可定位120毫米位移。 |
| 厚黑墙是否直接承重、空洞是否自动补门？ | 均不能。分别需要结构依据和另行明确的设计范围。 |

考核针对源图整理与尺寸关系，不代表任意PDF自动识别、建筑设计或活动CAD显示已通过。
