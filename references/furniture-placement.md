# 自由设计中的家具关系与使用空间

日期：2026-11-06

摘要：先确定家具的功能、靠墙关系、朝向和使用空间，再生成坐标。占地不碰撞只是必要条件，不代表布置合理。

## 设计顺序

1. 从房间用途确定必需家具和设备，保持已确定的墙、门、窗及固定设备位置。复绘任务按参考保留，不使用自由设计规则擅自重排。
2. 先布置主家具：床头选择适合的实墙段；衣柜和普通沿墙橱柜确定背墙；设备结合接管、散热、检修条件选位。检查窗洞、门套及安装间隙，不能仅把矩形放进房间中央。
3. 明确正面朝向及关联对象：沙发朝交流区或视听面；柜门朝可站立开启的一侧；床侧和床尾按使用人数与进出路径留空间。局部坐标的正面为负Y，背面为正Y；床头、沙发靠背及柜背均在正Y边，旋转同时改变使用区域。
4. 餐桌、茶几、岛台或有分区目的的独立沙发可以离墙。独立摆放须有具体功能理由，并核对周围使用和通行关系；不能用统一“居中”或“美观”替代布局判断。
5. 先画出使用区域，再检查入口到各功能区的路径。柜门开启、椅子拉出、床侧上下床、家电操作及维修空间分别考虑。数值来自明确设计输入、选用产品或适用依据，不把一个通用净距套在所有家具四周。
6. 比较至少一个可行备选的靠墙段或朝向，选择不挡门窗、动线顺畅、满足功能关系的布置；再进行模型坐标换算、工具校验和图面检查。

## 接口约束

`furnished_plan`的每件家具均须有`room`、`placement`、`clearances`、`clearance_basis`。原有只给坐标的带家具输入须补齐这些字段；工具不会擅自移动已给坐标。

```json
{
  "id":"bed-1", "kind":"bed", "room":"R2",
  "at":[6500,3875], "width":1800, "depth":2000, "rotation":0,
  "placement":{"mode":"wall","wall":"EXT","gap":0},
  "clearances":{"front":600,"left":600,"right":500},
  "clearance_basis":"原创模拟练习的毫米设计输入，非通用规范值"
}
```

以上示例仅适用于背边所在墙面为Y=5875的模拟房间；坐标和留距不得直接套用于其他户型。

- `placement.mode=wall`：指定墙ID和`gap`毫米间隙。检查旋转后的整条背边与实际墙面是否符合间隙，几何比较容差为1毫米；不能只有一个角靠近墙，也不能跨越洞口。间隙应对应安装条件，不能把悬空摆放的距离写成安装间隙规避检查。
- `placement.mode=freestanding`：填写`reason`说明分区、组合或使用目的；仍检查使用区域。理由文本只说明意图，程序不会据此自动证明设计合理。
- `clearances`：`front/back/left/right`为家具局部坐标对应边的外伸使用深度，单位毫米。须至少提供一个正值，并用`clearance_basis`说明来源或设计条件。程序检查已声明区域是否被墙、其他家具或门扇扫过区占据，是否越过室内边界。
- 使用区域之间可以重叠，例如相邻设施共享的通行空间；共享是否适合同时使用仍需结合具体活动判断。二维占地模型不处理桌椅上下穿插、柜门高度或窗台高度，不能把这种筛查当成三维设备安装验证。

`workbench_optimize`仅求解轴对齐矩形的几何排列，其统一`clearance`还作用于房间边界，不代表家具的功能留距或室内设计。求解位置须转换为上述关系明确的输入并校验；不能把矩形求解成功直接交付为家具方案。

## 检查与纠正

`WALL_PLACEMENT`先检查选墙、墙面坐标、家具背边方向、洞口和安装间隙；`USE_SPACE`检查正面方向、使用深度及具体障碍。纠正应保持任务范围，不能删除必要家具、把靠墙家具改成无理由独立摆放或缩小使用尺寸来消除报错。

保存后回读INSERT的位置、旋转、缩放和占地范围。床即使外包框不变，床头旋转到另一侧也应被识别为变化。最后观察整图，核对家具与房间用途、其他家具和交通的关系；关系检查通过与完整设计认可分别记录。
