# 食品加工学习要点（厂房、车间与设备）

日期：2026-11-24

摘要：食品工厂的CAD图纸组成，以及GB 14881-2013第3～5章对选址、车间布局、设施设备的要求如何落到图上。GB 14881部分为**已读条文归纳**（本轮实际读了国家卫健委公开的全文PDF第3～5章，用自己的话归纳）；其他部分为**教学归纳**和**复核项**。路线：`workbench_standards(operation="route", discipline="food_processing")`。

## 一套食品工厂图纸包含什么

| 图纸 | 内容 |
| --- | --- |
| 厂区总平面图 | 功能分区、生产区与生活区、污染源与垃圾站位置、道路与绿化、排水 |
| 车间工艺平面布置图 | 作业区划分（清洁/准清洁/一般）、设备定位、人流与物流路线、更衣洗手消毒点、检验室 |
| 洁净分区与气流图 | 各区洁净等级、压差或气流方向、缓冲间与风淋 |
| 给排水平面图 | 加工用水与其他用水分系统、地漏位置、排水坡向 |
| 通风空调平面图 | 进排气口位置、净化空调系统 |
| 工艺管道仪表图（P&ID） | 物料、CIP清洗、蒸汽等管路及阀门仪表 |
| 设备图 | 食品机械的总图、零件图（按机械制图要求） |
| 工艺流程图 | 从原料到成品的工序顺序 |

生产许可申请通常要提交设备布局图和工艺流程图，具体材料清单以现行《食品生产许可管理办法》和所在地市场监管部门要求为准（本轮未核实）。

## GB 14881-2013怎么落到图上（已读条文归纳）

`food-hygiene`，已读第3～5章，条号供定位，引用时以正文为准。

| 条号 | 要求（原创归纳） | 图上怎么检查 |
| --- | --- | --- |
| 3.2.2 | 厂区功能分区明显，有分离或分隔，防止交叉污染 | 总平面图有分区边界和名称 |
| 3.2.4、3.2.6 | 绿化与车间保持适当距离；生活区与生产区保持距离或分隔 | 总平面图量距离并标注 |
| 4.1.3 | 按清洁程度划分作业区（如清洁、准清洁、一般作业区），并有效分离或分隔；一般作业区与其他区分隔 | 每个房间标注所属作业区，区间有墙或隔断 |
| 4.1.4 | 检验室与生产区域分隔 | 检验室独立成间 |
| 4.2.2.3 | 蒸汽、水、电等管路避免设在暴露食品上方，确需设置时有防滴落措施 | 管线综合图与设备布置图叠合检查 |
| 4.2.3.2 | 墙、隔断与地面交界易于清洁，如做弧形交界 | 节点详图有墙地交界做法 |
| 4.2.4.2 | 清洁和准清洁作业区与其他区域之间的门能及时关闭 | 门表注明闭门方式 |
| 5.1.1.3 | 食品加工用水与不接触食品的用水用完全分离的管路，并标识区分 | 给排水图分系统、P&ID管线标识 |
| 5.1.2.2 | 排水入口装带水封的地漏 | 地漏图例与做法 |
| 5.1.2.4 | 室内排水从清洁程度高的区域流向低的区域，并防止逆流 | 排水坡向箭头不能从一般区流向清洁区 |
| 5.1.5.1 | 生产场所或车间入口设更衣室 | 入口处有更衣间 |
| 5.1.5.3 | 卫生间不得与生产、包装、贮存区域直接连通 | 卫生间门不直接开向这些区域 |
| 5.1.5.4 | 清洁作业区入口设洗手、干手和消毒设施，配套水龙头为非手动式 | 入口处设备定位与说明 |
| 5.1.6.1 | 通风避免空气从清洁度低的区域流向高的区域 | 气流或压差方向标注 |
| 5.1.6.2 | 进气口与排气口、户外垃圾存放处保持适当距离 | 平面上量距离 |
| 5.1.7.2 | 暴露食品上方的照明用安全型或有防护 | 灯具选型说明 |
| 5.1.8.3、5.1.8.5 | 原料、半成品、成品、包材分设或分区存放；清洁剂、消毒剂等化学品与之分隔 | 仓库分区标注 |
| 5.2.1.1 | 设备按工艺流程有序排列，避免交叉污染 | 设备布置顺序与流程图一致 |
| 5.2.1.3.2 | 设备不留空隙地固定在墙或地上，或与墙、地留足清洁维护空间 | 设备与墙的距离标注 |

## 常见错误自检

1. 卫生间门直接开向车间或包装间。
2. 排水坡向从一般作业区流向清洁作业区。
3. 清洁作业区与一般作业区共用一扇门，中间没有缓冲或更衣洗手。
4. 人流与物流路线交叉，或原料与成品走同一通道。
5. 管道、桥架走在敞开的食品或加工台上方，没有防滴落措施。
6. 设备紧贴墙但没有密封，也没留清洁空间。
7. 检验室与生产区没有分隔。

## 在本Skill中练习

- 分区和流线：`workbench_professional(profile_ids=["space"])`，图种`space.zoning`、`space.circulation`；工艺管道：`process_piping`路线和`workbench_industry`的`process_piping.pid`。
- 本仓库目前没有食品工厂专用的专业模板，按上表人工核对。

**练习（原创题）**：一个面包坊车间约18 m×12 m，工序为原料库→称量配料→和面→醒发→烘烤→冷却→内包装→外包装→成品库。要求：①把每个房间划入清洁、准清洁或一般作业区（冷却和内包装通常按清洁作业区考虑，最终以当地审查细则为准）；②画人流和物流路线，检查是否交叉；③布置更衣、洗手消毒和卫生间，检查卫生间不直接连通生产区；④画地漏和排水坡向，检查5.1.2.4的流向要求；⑤把检查结果逐条写成“条号—图上位置—结论”。
