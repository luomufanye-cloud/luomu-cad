# 景观设计学习要点

日期：2026-11-24

摘要：景观施工图的组成、总图与竖向表达、种植图和设计规范复核项。本页为**教学归纳**和**复核项**。路线：`workbench_standards(operation="route", discipline="landscape")`。

## 一套景观施工图包含什么

| 图纸 | 内容 | 对应图种ID |
| --- | --- | --- |
| 总平面图 | 用地红线、建筑、道路、铺装、水体、绿地和主要设施 | `landscape.masterplan` |
| 定位放线图 | 坐标网格、控制点坐标、主要尺寸 | — |
| 竖向设计图 | 设计等高线、控制点标高、坡度与坡向、排水方向 | `landscape.grading` |
| 种植设计图 | 乔木、灌木、地被分层表示，苗木表 | `landscape.planting` |
| 铺装与园路图 | 材料、拼缝、园路宽度与做法 | `landscape.paving` |
| 构筑物、小品、水景详图 | 平立剖面与节点 | — |
| 给排水、电气 | 由对应专业出图 | — |

北京地区的设计文件深度另见`beijing-landscape-depth`（DB11/T 335-2022）。

## 制图要点（教学归纳）

| 主题 | 要点 | 候选标准ID |
| --- | --- | --- |
| 总图单位 | 坐标、标高、距离以m为单位，一般至少取到小数点后两位；详图以mm为单位 | `site-plan-drawing` |
| 坐标 | 区分测量坐标（X、Y）与施工坐标（A、B），注明坐标系和高程基准；有指北针或风玫瑰 | `site-plan-drawing` `mapping-symbols` |
| 竖向 | 设计等高线与原地形等高线用不同线型区分；控制点标高与等高线不能矛盾；坡度写成i=…%并画坡向箭头；与建筑室内±0.000衔接 | `landscape-drawing` |
| 种植 | 苗木表列规格（胸径或地径、高度、冠幅）、数量和单位；图面图例区分常绿和落叶、乔木和灌木；图面株数与苗木表一致 | `landscape-drawing` |
| 图例与符号 | 植物、水体、铺装、地形的图例按风景园林制图标准，不自造含义冲突的图例 | `landscape-drawing` |

`site-plan-drawing`（GB/T 50103-2010）在索引中为`government_citation`等级，采用前先向发布机关核实现行状态。

## 设计规范复核项

| 复核什么 | 候选标准ID |
| --- | --- |
| 园林绿化工程的通用强制要求（全部条文强制） | `landscape-project-code` |
| 公园用地比例、园路、竖向排水、植物配置、建筑占地等 | `park-design` |
| 居住区绿地和公共空间指标 | `residential-planning` |
| 绿地分类与代码（公园绿地G1、防护绿地G2、广场用地G3、附属绿地XG、区域绿地EG） | `green-space-classification` |
| 无障碍园路、坡道和设施 | `accessibility` |

GB 55014、GB 55019的全文在住建部公告页附件公开。GB 51192-2016本轮只读了公告页，其强制性条文在GB 55014实施后的变化未核实。

## 常见错误自检

1. 竖向标高与排水方向矛盾，低点没有排水去向。
2. 种植点压在地下管线、构筑物或消防车道上。
3. 苗木表数量与图面株数不一致。
4. 没有注明坐标系、高程基准。
5. 等高线与标高点冲突，或等高线相交。

## 在本Skill中练习

- 专业模板：`workbench_professional(profile_ids=["landscape", "exterior"])`；已有经验见[景观视图拆解](../learned/landscape-view-decomposition.md)。
- 几何回读：`workbench_audit`检查重复线、零长度和自交。

**练习（原创题）**：一块40 m×30 m的场地，西南、西北、东北、东南四角设计标高分别为10.25、10.55、10.45、10.15（m），距西边24 m、南边12 m处设雨水口，标高9.95。要求：画出0.10 m间距的设计等高线；在汇集点注标高并画排水坡向箭头；算出各方向坡度i；检查有没有逆坡或无去向的低点。再在场地上布置10株乔木，做苗木表并核对图面株数。
