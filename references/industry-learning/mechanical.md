# 机械制图学习要点

日期：2026-11-24

摘要：零件图、装配图的组成和GB/T机械制图系列的核心约定。本页全部为**教学归纳**，挂到候选标准ID上，未逐条对照正文；尺寸、公差数值和条文以正文为准。路线：`workbench_standards(operation="route", discipline="mechanical")`。

## 一套机械图纸包含什么

| 图种 | 必须有的内容 |
| --- | --- |
| 零件图 | 一组视图；完整的定形、定位和总体尺寸；技术要求（尺寸公差、几何公差、表面结构、材料与热处理、未注公差说明）；标题栏 |
| 装配图 | 一组视图；规格、配合、安装、外形等必要尺寸；技术要求；零部件序号和明细栏；标题栏 |
| 焊接件图 | 在零件图基础上加焊缝符号、焊接方法和检验要求 |

## 制图要点

| 主题 | 要点（教学归纳） | 候选标准ID |
| --- | --- | --- |
| 图幅与图框 | A0 841×1189、A1 594×841、A2 420×594、A3 297×420、A4 210×297（mm）。留装订边时装订边a=25，其余边c=10（A0～A2）或5（A3～A4）；不留装订边时e=20（A0、A1）或10（A2～A4）。标题栏在图框右下角，看图方向与标题栏一致 | `drawing-sheets` `title-block` |
| 比例 | 优先1:1；缩小用1:2、1:5、1:10及其10ⁿ倍，放大用2:1、5:1、10:1。尺寸数字始终写零件实际尺寸，与比例无关 | `drawing-scales` |
| 字体 | 汉字用长仿宋体，字高系列1.8、2.5、3.5、5、7、10、14、20 mm，汉字字高不小于3.5 mm，字宽约为字高的1/√2 | `drawing-fonts` |
| 图线 | 线宽d从0.13～2 mm系列中选，机械图样只用粗、细两种，比例约2:1。粗实线画可见轮廓；细实线画尺寸线、尺寸界线、剖面线、引出线；细虚线画不可见轮廓；细点画线画轴线和对称中心线；细双点画线画相邻辅助零件、运动极限位置和假想轮廓；波浪线或双折线画断裂边界 | `mechanical-lines` `drawing-lines` |
| 投影与视图 | 国内默认第一角画法。主、俯视图长对正，主、左视图高平齐，俯、左视图宽相等。不在基本位置的视图（向视图、局部视图、斜视图）要用字母和箭头标注 | `drawing-projection` `mechanical-views` |
| 剖视与断面 | 全剖、半剖、局部剖按形状选；半剖以对称中心线为界。剖切位置用粗短画，箭头表示投射方向，视图上方注“A-A”。断面分移出断面和重合断面。肋板、轮辐被纵向剖切时不画剖面线，用粗实线与相邻部分分开 | `mechanical-sections` `simplified-drawing` |
| 剖面线 | 金属材料通用剖面线为细实线，一般与主要轮廓或对称线成45°。同一零件在各视图中方向和间隔一致；相邻零件方向相反或间隔不同 | `mechanical-hatching` |
| 尺寸 | 以mm为单位时不注单位。尺寸线用细实线，不能与其他图线重合或画在其延长线上。每个尺寸一般只注一次，注在最能反映形状的视图上。φ直径、R半径、Sφ球径、t厚度、C2表示45°倒角、EQS表示均布。角度数字一律水平书写。尺寸链要留一个不注尺寸的开口环 | `mechanical-dimensions` `simplified-dimensions` |
| 尺寸公差与配合 | 孔用大写、轴用小写公差带代号。零件图可注代号（φ30H7）、极限偏差或两者同注；装配图用分数形式注配合（φ30H7/g6）。一般优先基孔制。未注公差在技术要求中写明所用等级，如“未注线性尺寸公差按GB/T 1804-m” | `mechanical-tolerance-notation` `iso-fits` `general-tolerances` |
| 几何公差 | 公差框格从左到右依次为几何特征符号、公差值、基准字母；指引线箭头指向被测要素。箭头指在轮廓线上表示轮廓要素，与尺寸线对齐表示中心要素。基准用三角形加字母方框表示 | `gps-tolerances` |
| 表面结构 | 区分基本符号、要求去除材料和不允许去除材料三种图形符号。Ra单位为μm。符号尖端从材料外侧指向并接触表面，可注在轮廓线、尺寸界线或其延长线上。多数表面要求相同时可在标题栏附近统一标注；旧教材中“其余”字样的写法来自1993版，按2006版正文核对 | `surface-texture` |
| 螺纹 | 外螺纹大径画粗实线、小径画细实线；端视图中小径画约3/4圈细实线圆。螺纹终止线画粗实线。内螺纹剖开时小径画粗实线、大径画细实线。内外螺纹旋合部分按外螺纹画 | `mechanical-threads` |
| 齿轮 | 齿顶圆、齿顶线画粗实线；分度圆、分度线画细点画线；齿根圆画细实线或省略，剖视中齿根线画粗实线 | `mechanical-gears` |
| 焊缝 | 焊缝符号由指引线（箭头线和基准线）、基本符号及尺寸组成；箭头所指一侧和另一侧的焊缝在基准线上下分别标注 | `weld-symbols` |
| 序号与明细栏 | 序号指引线用细实线，从零件可见轮廓内引出，末端画圆点；序号按水平或竖直方向顺次排列。明细栏在标题栏上方，序号自下而上填写 | `mechanical-item-numbers` `parts-list` |
| 轴测图 | 用于辅助说明；正等测和斜二测最常用，轴间角与轴向伸缩系数按正文 | `mechanical-axonometric` |

## 常见错误自检

1. 三视图没有对齐（长对正、高平齐、宽相等不成立）。
2. 中心线、虚线与轮廓线线宽相同，或线型用错。
3. 尺寸重复标注、形成封闭尺寸链，或尺寸注在虚线上。
4. 同一零件在不同视图中剖面线方向或间隔不一致。
5. 零件图上写了配合代号（H7/g6），或缺少未注公差说明。
6. 表面结构符号尖端方向反了，或标在不可见轮廓上。
7. 螺纹大径、小径的粗细线画反。
8. 标题栏比例与实际出图比例不符。
9. 仍引用已废止的旧版本：GB/T 1800.1-2009《极限与配合》、GB/T 131-1993、GB/T 4457.5-1984《剖面符号》。现行版本见标准索引。

## 在本Skill中练习

- 专业模板与实测检查：`workbench_professional(profile_ids=["mechanical"])`；图种合同：`workbench_industry`的`mechanical.part`、`mechanical.assembly`、`mechanical.inspection`。
- 实体零件：按[实体建模与量测验收](../solid-model-review.md)用`workbench_solid`运行`examples/solid-mounting-plate.py`，对生成的视图按上表逐项自检视图关系、线型线宽和孔的定位尺寸。
- 几何回读：`workbench_audit`检查零长度、重复线和尺寸覆盖。

**练习（原创题）**：一根阶梯轴，总长120 mm；左段φ30、长40，与轮毂配合；中段φ36、长20；右段为M20外螺纹、长25，其余为φ24光轴；φ30段上有一个键槽。要求：画主视图和键槽处移出断面；注全尺寸并检查没有封闭尺寸链；φ30段注轴的公差带代号；配合面注表面结构；技术要求中注明未注公差等级。完成后对照“常见错误自检”逐条检查，并把每条用到的标准ID写进标准依据记录。
