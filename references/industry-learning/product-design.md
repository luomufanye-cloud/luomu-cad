# 产品设计学习要点（工业设计、家具、包装）

日期：2026-11-24

摘要：产品设计图纸的组成、人体尺寸的使用方法和家具、包装标识的依据。工程图部分沿用[机械制图要点](mechanical.md)。本页为**教学归纳**和**复核项**；人体尺寸、家具尺寸等数值一律取正文。路线：`workbench_standards(operation="route", discipline="product")`。

## 一套产品设计文件包含什么

| 文件 | 内容 |
| --- | --- |
| 设计定义 | 使用人群（性别、年龄段、地区）、使用场景、关键尺寸约束 |
| 外观三视图 | 第一角画法，主要外形尺寸，与效果图一致 |
| 人机尺寸分析图 | 关键尺寸对应的人体尺寸项目、百分位和修正量，标注数据来源表号 |
| 结构爆炸图、装配图 | 零件序号与明细栏 |
| 零件图 | 塑料件的壁厚、拔模、圆角；材料与表面处理；公差与表面结构 |
| CMF说明 | 颜色、材料、表面工艺 |
| 包装与储运标识 | 包装结构图、储运图形符号位置 |

## 人体尺寸怎么用（教学归纳）

1. **选数据**：成年人取`body-dimensions-adult`（GB/T 10000-2023），未成年人取`body-dimensions-minor`。官方目录显示GB/T 10000-1988已废止，不要再用旧教材里的1988版表格。
2. **判类型**：`body-percentiles`（GB/T 12985）按产品尺寸设计类型选百分位。教材常见的分类是：
   - 需要上下两个限值的（如可调座椅高度）：用一大一小两个百分位定调节范围；
   - 只需上限、要让大个子也能用的（如门洞、通道净高）：用大百分位；
   - 只需下限、要让小个子也够得着的（如操作件伸及距离）：用小百分位；
   - 只需平均值的：用第50百分位。
   涉及安全健康的产品取更高的满足度。具体分类名称、百分位和满足度对照表以GB/T 12985正文为准。
3. **加修正量**：功能尺寸 = 人体尺寸百分位数 + 功能修正量（如鞋跟、衣着、姿势）+ 必要的心理修正量。修正量要写明依据。
4. **查空间与岗位**：工作空间和岗位尺寸见`workspace-body`、`workstation-dimensions`。这两项发布较早，与2023版人体数据一起使用时要说明换算。
5. **记来源**：每个关键尺寸写明标准号、表号、百分位和修正量，进标准依据记录。

常见错误：只用第50百分位设计“平均人”；混用不同年份的数据；忽略性别和年龄段；只有效果图没有尺寸推导。

## 家具与包装（复核项）

| 对象 | 检查什么 | 候选标准ID |
| --- | --- | --- |
| 桌、椅、凳 | 桌面高、座高、座深等主要尺寸是否落在标准范围，及尺寸级差 | `furniture-tables` |
| 柜类 | 柜体主要尺寸、搁板层间高度等 | `furniture-cabinets` |
| 床类 | 床面长宽高等 | `furniture-beds` |
| 储运标识 | 用2025版图形符号，核对颜色、尺寸、位置和数量要求 | `packaging-marks` |

数值全部取正文。官方目录显示家具三项的1997版、GB/T 191-2008均已废止。定制柜体的平面、立面、侧剖可用`workbench_casework`生成并回读，见[共享尺寸多视图](../casework-multiview.md)。

## 在本Skill中练习

- 专业模板：`workbench_professional(profile_ids=["product"])`；图种合同：`workbench_industry`的`product.part`、`product.assembly`、`product.manufacturing`，家具用`furniture.*`。
- 实体零件和STEP：`workbench_solid`，见[实体建模与量测验收](../solid-model-review.md)。

**练习（原创题）**：设计一张可升降站立办公桌，使用人群为成年男女。要求：判断台面高度属于哪类尺寸设计；从GB/T 10000-2023正文查所需人体尺寸项目和百分位，记录表号；加上鞋跟修正量后算出升降范围；画外观三视图并注升降范围；在人机尺寸分析图上写明每个数的来源。没有取得正文时，只完成方法和表格结构，数值栏写“待取正文”，不要用记忆中的数值代替。
