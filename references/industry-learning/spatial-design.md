# 空间设计学习要点（室内）

日期：2026-11-24

摘要：室内设计施工图的组成、房屋建筑制图通用约定和设计规范复核项。制图约定为**教学归纳**；设计规范部分只列**复核项**，数值取正文。路线：`workbench_standards(operation="route", discipline="interior")`。

## 一套室内施工图包含什么

| 图纸 | 内容 | 对应图种ID |
| --- | --- | --- |
| 原始结构/测量图 | 现状墙体、柱、梁、门窗洞、层高和设备点位 | `interior.original_frame` |
| 拆改墙体图 | 拆除和新建墙体分别表示，承重构件不得擅改 | — |
| 平面布置图 | 家具、洁具和设备布置，主要尺寸 | `interior.layout` `interior.furniture_dimensions` |
| 地面铺装图 | 材料、拼缝、起铺点和完成面标高 | `interior.floor_finish` |
| 顶棚平面图 | 吊顶造型、标高、灯具和风口 | `interior.ceiling` `interior.ceiling_dimensions` |
| 灯具与开关插座定位图 | 与电气专业对接 | `interior.lighting` `interior.switching` |
| 立面图 | 由平面上的立面索引符号引出，编号与图名一致 | — |
| 节点详图 | 材料构造、收口和尺寸 | — |
| 材料表、门窗表、设计说明 | 与图面一致 | — |

## 制图约定（教学归纳）

候选标准：`building-general`（GB/T 50001-2017，本仓库已读部分条文，见[标准基础](../standards-foundation.md)）、`interior-drawing`（JGJ/T 244-2011）。

| 主题 | 要点 |
| --- | --- |
| 线宽 | 先定基本线宽b（常用1.4、1.0、0.7、0.5 mm），再按b、0.7b、0.5b、0.25b成组使用 |
| 尺寸 | 尺寸起止符号用中粗斜短线，与尺寸界线顺时针成45°，长约2～3 mm；半径、直径、角度、弧长用箭头。尺寸界线离开轮廓不小于2 mm，超出尺寸线2～3 mm。平行尺寸线间距7～10 mm，最内一道距轮廓不小于10 mm |
| 标高 | 以m为单位，一般注到小数点后三位，零点写±0.000；室内区分完成面标高和结构标高 |
| 索引与详图符号 | 索引符号为直径8～10 mm的细实线圆，详图符号为直径14 mm的粗实线圆；上半圆写详图编号，下半圆写所在图号 |
| 定位轴线 | 细点画线；编号圆直径8～10 mm；横向用阿拉伯数字从左到右，竖向用大写拉丁字母从下到上，不用I、O、Z |
| 比例 | 平面常用1:50、1:100；立面常用1:20～1:50；节点常用1:1～1:10 |

具体数值以GB/T 50001-2017正文为准；室内专用的立面索引、材料图例按JGJ/T 244正文。

## 设计规范复核项

| 复核什么 | 候选标准ID |
| --- | --- |
| 室内净高、楼梯、栏杆高度和杆件净距、台阶与坡道、门窗安全 | `civil-building-code` `civil-building-unified` |
| 无障碍通道宽度、轮椅回转空间、坡道、门、无障碍卫生间 | `accessibility` |
| 装修材料燃烧性能等级（A、B1、B2、B3）；不得遮挡消火栓、疏散指示和安全出口；疏散走道和楼梯间的材料要求 | `interior-fire` `building-fire` |
| 隔声、采光、室内空气质量 | `building-environment` |
| 各类房间照度、眩光、显色性和照明功率密度 | `lighting` |
| 家具尺寸和人体尺寸 | `furniture-tables` `furniture-cabinets` `furniture-beds` `body-dimensions-adult` |

GB 55031、GB 55019、GB 55016是强制性工程建设规范，住建部公告页附件公开全文，可直接阅读并记录条号。GB 50352-2019、GB 50222-2017的强制性条文已分别列入GB 55031、GB 55037公告的废止清单，引用前要确认用的是哪一份的条文。

## 常见错误自检

1. 平面布置图与顶棚平面图轴线、墙体不对位。
2. 立面索引编号与立面图名对不上。
3. 标高用了mm，或完成面与结构标高混用。
4. 尺寸起止符号用了箭头（建筑类图纸一般用斜短线）。
5. 家具尺寸凭感觉，没有尺寸依据。
6. 装修造型遮挡消火栓、疏散指示或检修口。
7. 拆改图动了承重墙、梁柱，没有结构专业确认。

## 在本Skill中练习

- 房间平面、地面与顶棚完成面、墙面立面、剖面和PDF图册：`workbench_project`，见[共享项目与图册联动](../shared-project-atlas.md)。
- 门窗、家具、洁具构件：`workbench_components`；柜体：`workbench_casework`。
- 专业模板：`workbench_professional(profile_ids=["interior", "space"])`。

**练习（原创题）**：用`workbench_project`（或`scripts/build_project.py`）按`examples/shared-project.json`生成房间图册，然后：①检查平面与顶棚对位；②核对立面索引编号与立面图名；③列出需要按GB 55019复核的位置（入口、卫生间、通道），到公告页附件正文中找到对应条号，记进标准依据记录。
